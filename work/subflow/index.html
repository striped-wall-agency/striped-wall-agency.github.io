02 / Context & task

Make every change
easy to understand.

A plan change or cancellation affects more than a label on a screen. Customers need to know what they will pay and when a change takes effect. Operators need a clear view of each subscription’s current state.

Subflow makes those decisions visible before they are confirmed, then carries the updated state through the customer and admin views.

Product questionHow can customers manage their subscription with confidence while operators keep a clear view of every change?

05 / Product decisions

Make the next state clear.

Subscription changes are easier to trust when the interface explains what will happen, when it will happen, and where that state appears next.

01 / TIMING

Make the effective date visible

A plan change appears as upcoming, so customers can see when the new plan and price will apply.

02 / LIFECYCLE

Let time move the demo forward

The demo clock makes renewal boundaries and subscription status changes explorable across both roles.

03 / SHARED VIEW

Keep both roles connected

Changes in the customer portal appear in the admin workspace through shared subscription data.
